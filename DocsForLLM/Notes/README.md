# Local notes

This folder is for note-taking only: working notes, plans, proposals, investigation findings, and drafts. Notes are not approved decisions, standing instructions, or authorization to implement or operate anything.

Keep general guidance directly in [DocsForLLM](../README.md) and confirmed decisions in [ADR](../ADR/). Required guidance and decisions must not live only in local notes.

Only this README is intended for version control. All other files and subdirectories here are gitignored; do not force-add notes.

If `README.gitignored.md` exists in this folder, read it before using any other note. It is the local master note: an index of the notes here and their status. It is gitignored, so a fresh clone will not have it.
